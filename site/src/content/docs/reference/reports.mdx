Some standards do not stop at the number. They say what a report of it looks
like: which metadata goes in the header, which quantities go in the table, how
the curve is drawn beside it, and what the single-number result is called at
the bottom. Where a standard does that, the result object renders that page,
and this is every one of them.

A fiche is not a certificate. It is the library laying out its own result in
the format the standard asks for, which makes it easy to check against a
report somebody else produced and easy to paste into one of your own. The
numbers on it come from the same call you would make in a script, so what it
claims is exactly what the [conformance report](/phonometry/reference/conformance/)
holds the library to.

Each title below links to the PDF, and the line under it to the guide that
shows the measurement. The description is the one that guide writes for a
reader who cannot see the page.
