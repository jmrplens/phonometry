# phonometry documentation: robots.txt
# All crawlers are welcome, including AI and generative-engine crawlers.
#
# Served at https://phonometry.dev/robots.txt, the root of the host: it is the
# file crawlers read, and it speaks for every path of the site.
#
# Structured context for LLMs:
#   https://phonometry.dev/llms.txt
#   https://phonometry.dev/llms-full.txt
# and every page as Markdown, beside it at <page>/index.md, the two landing
# pages included:
#   https://phonometry.dev/signals/levels/levels/index.md
#   https://phonometry.dev/index.md
#
# The same AI policy, in the dialects other crawlers read:
#   https://phonometry.dev/ai.txt                  Spawning's ai.txt
#   https://phonometry.dev/.well-known/tdmrep.json  W3C TDM Reservation Protocol,
#                                                   "tdm-reservation": 0
# The three say one thing and change together: site/scripts/public-files.test.mjs
# fails when they disagree.
#
# Content Signals (https://contentsignals.org/, IETF draft-romm-aipref-
# contentsignals) define exactly three keys: search, ai-input and ai-train.
# A key outside that list is ignored, so none is added here.
#
# The signal is repeated in every named group. Under RFC 9309 a crawler obeys
# exactly one group, the most specific one that matches it, and ignores the
# rest, `*` included: declared only under `*`, the opt-in would be invisible to
# the very crawlers named below. A new group copies the line.

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=yes
Allow: /
